# lab_2_react

React-версія резюме (Частина 2 лабораторної роботи №2). Проєкт створено шаблоном Vite `react`.

```bash
npm install     # встановити залежності
npm run dev     # сервер розробки на http://localhost:5173
npm run build   # продакшн-збірка в dist/
npm run lint    # перевірка ESLint
```

## Компоненти

| Компонент | Що робить |
|---|---|
| `App` | зберігає мову (`useState`) і передає потрібний текст іншим компонентам |
| `Header` | ім'я, навігація по розділах, перемикач UA/EN |
| `Hero` | перший екран: бейдж і короткий опис |
| `Badge` | бейдж на ремінці, перевертається і показує Proof of Meet |
| `QrCode`, `NfcIcon` | SVG-графіка для бейджа |
| `ContactLinks` | список контактів, використовується тричі з різним `variant` |
| `Section` | спільна обгортка розділу (заголовок + `children`) |
| `Experience`, `Achievements`, `Timeline`, `Skills`, `Education` | розділи резюме |
| `Footer` | контакти внизу сторінки |
